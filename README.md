# Ближе — агент для личного Telegram

Локальная панель для общения через **ваш личный аккаунт Telegram (MTProto)**: контакты, автоответы с раскрытием ИИ, профиль вашего стиля и конспекты перед свиданиями. Интерфейс на русском, работает на компьютере и телефоне.

## Возможности

- Добавление по ID, `@username` или из последних 100 личных диалогов. Удаление контакта вместе с его данными в приложении.
- Вход в существующий Telegram-аккаунт по номеру, коду из Telegram/SMS/email и паролю 2FA.
- Для каждого контакта: автоответы, черновики по запросу, пауза, заметки.
- Уведомление об ИИ отправляется отдельной кнопкой. Для автоответов собеседница подтверждает совершеннолетие и обработку переписки командой `/agree`. `/stop`, «стоп» и явные просьбы не писать останавливают агента.
- Ваш личный ответ из Telegram автоматически ставит соответствующий контакт на паузу.
- Анализ только **ваших** сообщений из Telegram JSON: выбранный чат, явно выбранный автор, до 100 последних примеров. Результат можно редактировать. Это извлечение правил стиля, не fine-tuning модели.
- Импорт истории выбранного личного чата (до 3000 текстовых сообщений) с защитой от повторного импорта.
- Карточки встреч: дата, место, заметки, статус. После добавления автоматически создаётся конспект последних 300 сообщений; можно обновить и скачать TXT.
- Конкретные договорённости, неоднозначные и чувствительные ситуации направляются на ручную проверку. Встречу в календаре приложения подтверждает владелец.
- Демо с вымышленными данными, которое не подключается к Telegram или OpenAI.

## Быстрый просмотр

Нужен Node.js 20.12+ (рекомендуется поддерживаемая LTS-версия) и npm.

```sh
npm ci
npm run demo
```

Откройте <http://127.0.0.1:3210>. Демо использует отдельный `data/demo.json`, имитирует ИИ фиксированными примерами и никогда не отправляет настоящие сообщения. После настройки рабочего режима остановите демо, чтобы освободить порт.

## Запуск с вашим аккаунтом

```sh
npm run setup
```

Команда создаст **локальный** `.env` со случайными `ADMIN_PASSWORD` и `ENCRYPTION_KEY`. Повторный запуск ничего не перезаписывает. Откройте `.env` в редакторе и заполните:

| Переменная          | Значение                                                       |
| ------------------- | -------------------------------------------------------------- |
| `TELEGRAM_API_ID`   | Ваш API ID из [API development tools](https://my.telegram.org) |
| `TELEGRAM_API_HASH` | API hash оттуда же                                             |
| `OPENAI_API_KEY`    | Ключ проекта OpenAI с доступом к Responses API                 |
| `OPENAI_MODEL`      | Модель со Structured Outputs; по умолчанию `gpt-4.1-mini`      |
| `OWNER_NAME`        | Ваше имя для уведомления об ИИ                                 |
| `ADMIN_PASSWORD`    | Уже сгенерирован; пароль входа в панель                        |
| `ENCRYPTION_KEY`    | Уже сгенерирован; 32 байта в hex для AES-256-GCM               |

```sh
npm start
```

1. Откройте <http://127.0.0.1:3210> и введите `ADMIN_PASSWORD`.
2. В «Настройках» подключите **существующий личный аккаунт**: номер → код → 2FA при необходимости. Вводите данные только в своём локальном приложении.
3. В «Мой стиль» загрузите JSON из Telegram Desktop: меню личного чата → «Экспорт истории чата» → формат JSON. Выберите диалог и своего автора. Предварительно удалите личные сведения, которые не нужны для анализа.
4. Добавьте контакт. Если известен только ID, пользователь должен быть среди последних 100 доступных диалогов; иначе используйте `@username`. Группы, каналы, боты и Saved Messages не поддерживаются.
5. Откройте диалог в панели и отправьте уведомление об ИИ. После `/agree` новые текстовые сообщения будут получать автоответы, если контакт активен, создан профиль стиля и общая пауза выключена.
6. При желании импортируйте историю этого диалога. При импорте подтвердите право на обработку. Импорт сам по себе не отправляет ответы и не меняет согласие.
7. Когда договоритесь о свидании, добавьте встречу. Конспект создастся автоматически. Если ИИ временно недоступен, встреча сохранится, а конспект можно создать позже кнопкой.

Вход в панель не равен входу в Telegram. Выход из панели оставляет агента работающим. «Выйти из Telegram» отзывает сессию приложения и включает общую паузу. Обычный `Ctrl+C` также включает общую паузу: после перезапуска возобновите работу явно. Завершить сессию можно и в официальном Telegram → «Устройства».

Пространство привязывается к одному Telegram ID. Для другого аккаунта используйте отдельную папку данных и другой порт. Не запускайте несколько процессов над одним файлом данных.

## Данные и отправки

- Сервер по умолчанию доступен только на `127.0.0.1`. Админ-пароль обязателен; сессии панели — HttpOnly/SameSite cookies, изменяющие запросы требуют CSRF-токен. Есть ограничение попыток входа.
- В рабочем режиме переписки, заметки, профиль и сессия Telegram шифруются AES-256-GCM. Запись состояния атомарная, файл синхронизируется перед заменой.
- `.env`, `data/`, Telegram-сессии и реальные экспорты **не должны попадать в Git**. `.env` и `data/` уже исключены; загруженные JSON-файлы не сохраняются. Не кладите исходные экспорты в папку репозитория.
- Сохраните резервную копию `.env` и зашифрованной папки `data/` отдельно. Потеря ключа делает данные нечитаемыми; шифрование не защищает от доступа к работающему процессу или одновременно к `.env` и данным.
- OpenAI получает выбранные собственные примеры для стиля, последние 60 сообщений выбранного контакта и ваши заметки для ответа, последние 300 сообщений для конспекта. Передаётся `store: false`. Это не обещание нулевого хранения у провайдера — действуют настройки и политика его API.
- Telegram-токены, `access_hash`, ключи, коды и пароли не возвращаются в панель. Коды и пароль 2FA не записываются на диск.
- Лимиты: 30 заданий автоответа в час на контакт; 30 отправок в час на контакт и 10 в минуту суммарно. При FloodWait приложение не пытается обходить ограничение Telegram.
- Повторные события от Telegram дедуплицируются. При неизвестном результате отправки статус — «Доставка не подтверждена»: нет слепого повтора. Сверьте сообщение в Telegram. Если оно не доставлено, создайте новый ответ вручную.
- Пауза, удаление контакта, ручной ответ или отзыв согласия во время генерации блокируют последующую автоматическую отправку. Уже переданный Telegram сетевой запрос отозвать нельзя.
- Telegram Client API доставляет события клиенту; приложение сохраняет текст только выбранных личных диалогов. Другие диалоги не передаются ИИ и не сохраняются. Список имён последних диалогов загружается только для выбора контакта.

## Ограничения первой версии

Один владелец и один процесс, текстовые личные сообщения. Голосовые, изображения, секретные чаты, редактирование/удаление сообщений в Telegram и надёжная синхронизация пропущенного за время отключения не реализованы. Прерванные задания после рестарта не отправляются автоматически; проверяйте диалоги вручную. У агента нет фона, если компьютер или процесс выключен.

Для новых схем авторизации, требующих настройки email или CAPTCHA, завершите настройку в официальном Telegram. Автоматическая регистрация аккаунтов и обход ограничений не реализованы. Если истёк код, нажмите «Начать вход заново».

Анализ стиля и конспекты могут ошибаться: просматривайте их, особенно договорённости. По ID незнакомого пользователя нельзя гарантировать доступ: Telegram требует доступный вашему аккаунту `access_hash`. См. [Peer database](https://core.telegram.org/api/peers).

Для удалённого доступа используйте HTTPS reverse proxy, `COOKIE_SECURE=true`, `HOST=0.0.0.0` и `ALLOWED_HOSTS=ваш.домен`; открывайте порт только внутри доверенной сети прокси. Демо принудительно ограничено loopback. Публичный хостинг в этот репозиторий не включён.

## Проверки

```sh
npm run check
npm test
npm run test:e2e
```

Unit/API тесты проверяют согласие, гонки с `/stop`, паузой и удалением, ручной перехват, дубли событий, неизвестную доставку, устаревшие черновики, JSON-импорт, шифрование, формат запросов ИИ, авторизацию и CSRF. E2E проверяет пользовательские сценарии и мобильную ширину в браузере. Локально используется установленный Microsoft Edge; в CI устанавливается Chromium.

Проверки не отправляют сообщения реальным людям и не расходуют API OpenAI. Живое подключение Telegram и качество ответов нужно проверить со своим аккаунтом и ключом после настройки.

## Структура

- `src/telegram.js` — MTProto, авторизация, зашифрованная сессия.
- `src/engine.js` — согласие, очередь ответа, остановки, отправки.
- `src/ai.js` — OpenAI Responses API и проверяемые JSON-схемы.
- `src/import.js` — выбор чата/автора и импорт Telegram JSON.
- `src/store.js`, `src/crypto.js` — локальное хранение и шифрование.
- `src/app.js` — защищённый HTTP API; `public/` — интерфейс без сборки и внешних CDN.
- `test/`, `e2e/` — автоматические проверки.

Основа Telegram-интеграции — [teleproto](https://docs.teleproto.dev/), поддерживаемый преемник GramJS. Формат ответов ИИ — [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).
